# 2026-11-22｜音色比較のための録音・FFT測定設計

分類: 音響測定 / 基礎研究。**机上設計のみ。録音・実機試験・最新SynthApp.cpp精読は未実施。**

## 研究の問いと一次資料
「GM音色素材の倍音」「TVFの効き」「ENVの時間」「GLIDEの段差」を同じFFT画像だけで判定できるか。**できない**。周波数平均と時間変化の観測は異なる。

- Audacity公式 [Plot Spectrum](https://manual.audacityteam.org/man/plot_spectrum.html) : 選択区間の複数FFTブロックを平均。FFT長と時間分解能のトレードオフ、Hann窓、ステレオ選択時のチャンネル加算に注意。
- Audacity公式 [Spectrogram Settings](https://manual.audacityteam.org/man/spectrogram_settings.html) : FFT窓長、窓関数、zero paddingの意味。zero paddingは真の分解能を上げない。
- SciPy公式 [signal.welch（1.16）](https://docs.scipy.org/doc/scipy-1.16.0/reference/generated/scipy.signal.welch.html) : 分割・重複・平均でPSDを推定。densityとspectrumの単位は異なる。
- [SciPy実装 _spectral_py.py / welch](https://github.com/scipy/scipy/blob/main/scipy/signal/_spectral_py.py) : 関数定義を公開ソースで照合。**実装全体の精読は未実施**。mainと1.16のデフォルト引数が同一とは断定しない。
- [DinMeter既存レビュー](../2026-11-10-sam2695-design-review.md) : SAM2695内蔵TVF/ENV、3 OSC、32ms MOD、5ms Glideは**2026-11-10時点のコードレビュー**に基づく。最新コードは未読。

## 1. 音声・制御経路
DinMeter: USB鍵盤→ESP32のノート/変調制御→MIDI UART→SAM2695内部のROM音色再生・TVF・音量ENV・FX→アナログ出力→録音インターフェース→PCM→FFT/時間波形。
OSC→Mixer→Filter→VCAという概念はSAM2695内部に閉じ、録音は**最終出力の観測**。TVFを変えるMIDI命令は制御信号であり、音声サンプルではない。
各鍵のROM音源内部ボイスの独立性はチップ内部実装に依存し、録音した全体出力から直接断定できない。ESP32側のMOD状態はOSC/MIDIチャンネル側で共有される設計（既存レビュー）。

## 2. 測定の原理と使い分け
- **定常倍音**：Attackを除いたSustain区間を同一長さ・同一レベルで選び、Hann窓のFFTまたはWelch平均。44.1kHzで4096点ならビン間隔は約10.77Hz、観測窓は約92.9ms。16384点なら約2.69Hz、約371.5ms。これは**ビン間隔**であり、実際の近接成分分離能力と同一ではない。
- **Attack/Release**：PCMの短時間RMS包絡（例10ms/20ms窓）と時系列波形。長い区間の平均FFTではENV曲線や再トリガを判定できない。
- **GLIDEの滑らかさ**：スペクトログラム/短時間ピッチ追跡を使用。5msのMIDI更新間隔がそのまま可聴段差を意味するとは限らない（SAM内部補間やROM音色の非定常性は未確認）。短い窓は時間精度に優れるが低域のピッチ分離に不利。
- **TVF効果**：同じROM素材・鍵域・velocity・ENV・FX OFFの条件でcutoff設定だけを変え、基本波に対する高次倍音の相対変化を比較。絶対音量差やサンプル鍵域切替を混同しない。
- **コーラス/ステレオ**：L/Rを個別に測る。Audacity Plot Spectrumはステレオ同時選択時にチャンネルを合算するため、位相差で結果が変わり得る。モノラル合算のグラフからステレオの広がりを結論づけない。

## 3. 録音条件（実験計画、未実施）
同じMIDIノート（例C3/C4/C5）、velocity固定、ノート長固定、録音ゲイン固定、サンプルレート/bit depth固定、無圧縮WAV。各条件3回以上、Attack・Sustain・Releaseの切り出し時刻を記録。まず1 OSC・GMレイヤーOFF・MOD/FX OFFで基準録音し、次に変える要素は1つだけ。録音入力でクリップしないことを波形ピークで確認。SAMの左右出力/録音機器の接続方式、内部FX完全OFFの可否は未確認。音量正規化は**元音量差の情報を消す**ため、生データとレベル整合版を分ける。

## 4. 反証と測定上の落とし穴
- 「倍音が増えた＝フィルターが開いた」は誤り得る。サンプルのvelocity切替、ENV時間、歪み、録音クリップでも高域が変化する。
- 「FFTピークが太い＝音が太い」は成立しない。窓関数・長さ・録音レベル・周波数分解能で見かけが変わる。
- 「スペクトログラムで階段状＝Pitch Bendの段差」は仮説に留まる。録音側の時間分解能と音源内部補間を切り分ける。
- 「SAMのcutoff値＝Hz」は根拠なし。測定後も**相対指標**から始める。単一音色の倍音変化だけでフィルター伝達関数を一意に復元できない。
